# 喵喵生活（安卓 PWA）· 柔和界面风版

一个移动端生活理财 App，包含**比价**（奶粉 / 纸尿裤 / 加油站油价多平台对比）和**记账**（收支、预算、统计）两大模块。基于纯前端技术，无需后端即可运行，可添加到安卓主屏幕像原生 App 一样全屏使用，支持离线打开。

> 🎨 **本版本 UI 采用「柔和界面风」重塑**：靛蓝 `#6366f1` 主色、雾灰 `#f1f5f9` 画布、卡片 24px / 按钮输入 16px 大圆角、带主色相的彩色柔光阴影、低饱和配色、300–500ms 上浮动效，并适配减少动态效果偏好。功能与数据模型与稳定版完全一致。
>
> 📌 稳定版（原蓝色主题）保留在项目根目录的 `../price-compare-app/`，本目录 `price-compare-app-v2/` 为独立的柔和 UI 版本，两者互不影响。

> ⚠️ App **不内置任何商品**。所有商品与价格均由你手动录入，数据保存在本机浏览器。

## 界面结构

- **首页**：大类入口按钮（奶粉 / 纸尿裤 / 加油 / 记账），点击才进入对应模块
- **记账模块**（`bookkeeping.html`）：来自「满满记账」工具，含首页、日历、记账、统计（含饼图）、我的五个页面；支持收支记录、月度预算、数据导入导出。右上角「‹ 比价」可返回比价首页
- **分类页**：商品列表、低价榜、搜索、排序、「＋录入」和「📊 对比」入口
- **横向对比页**：参考奶粉/纸尿裤比价工具，按**单位价格**（奶粉元/克、纸尿裤元/片、加油元/升）对商品横向排名，标注优势（单价最低/总价最低/平台最多/折扣最大），并给出智能推荐语。录入商品可直接在此删除。
- **录入/编辑页**：填写**规格公式自动算总量**、优惠自动算**到手价**，或**📷 截图识别**自动填入
- **详情页**：各平台价格对比、降价提醒、编辑价格、删除
- **我的**：录入的商品、降价提醒、数据说明、清除数据

## 功能

- 三类商品比价：奶粉、纸尿裤、加油（92# / 95# / 98#）
- **📷 截图识别**：新建或编辑商品时，拍照/选商品截图，自动识别品牌、名称、规格数量、价格，确认后一键填入表单
- **手动录入 / 编辑 / 删除**商品及各平台价格（录入商品卡片、详情、对比页均可删除），本地保存并参与比价
- **结构化规格**：按「购买份数 / 单份数量 / 赠送份数 / 赠送单份数量」填写（参考奶粉比价工具），自动算出合计总量，如 2罐×900g + 赠1罐×130g = 1930g；规格明细会保存，编辑时可回填
- **消耗参数 + 可使用天数**：设置消耗参数（奶粉：每日顿数×每顿勺数×每勺克数；纸尿裤：每日片数；加油：每日升数），自动算出每个商品「可用约 N 天」，在详情页和对比页展示
- **优惠到手价**：优惠填 `满199减30`、`9折`、`95折`、`减20` 等自动换算到手价；未满门槛不生效。**所有比价、单价、排名、推荐均用到手价**，不再用标价
- 多平台价格对比表，自动高亮最低到手价、显示原价/优惠与省钱金额
- 今日低价榜（按折扣力度）、关键词搜索（品牌/商品/平台）、多种排序
- 收藏商品、设置降价提醒（本地存储）
- 离线缓存（App 本身）、可安装到桌面

## 关于截图识别（完全离线）

- 采用浏览器端 OCR（Tesseract.js 5），**引擎、wasm 核心、中文模型全部随 App 部署在 `vendor/` 目录**（约 9MB），首次打开即从本地加载，**识别全程无需联网**，图片不上传、不经过任何服务器。
- 使用官方 `best_int` 精简中文模型（1.7MB，精度优于标准版），兼顾体积与识别率。
- `ocr.js` 采用「本地优先、CDN 兜底」：若 `vendor/` 文件缺失才会回退到在线加载。Service Worker 会把这些文件缓存到本地，断网也能识别。
- 浏览器无法静默截取手机屏幕，交互为「拍照 / 从相册选截图 → 识别」。
- 识别结果有不确定性：弹层会展示**候选字段与原文**，请核对后点「填入表单」，可手动修正。价格候选可点选其中一个填入。
- 识别失败时，仍可完全手动录入，不影响其他功能。

## 关于"自动从官网抓取价格"

电商官网（京东/天猫/拼多多等）有**反爬机制 + 浏览器跨域限制**，纯前端 App 无法直接抓取其价格。可行路径：

1. **手动录入**（已实现）：在分类页点「＋录入」，填写各平台价格，App 自动比价。这是当前最可靠的方式。
2. **官方开放平台 API**：向各电商申请商品/价格查询授权，后端聚合后提供给 App（见下方接入说明）。
3. **第三方数据服务商**：使用合规的比价数据 API。
4. 加油站油价可接入发改委或第三方油价 API。

## 部署到 GitHub Pages（在线访问，推荐）

本项目是纯静态 PWA，可直接托管在 GitHub Pages，免费、自带 HTTPS（Service Worker 安装的必要条件）。仓库已内置 `.nojekyll` 和 `.github/workflows/deploy.yml`，push 后自动发布。

**步骤：**
1. 在 GitHub 新建一个仓库（建议设为 Public，例如 `miaomiao-life`）。
2. 把本目录（`price-compare-app-v2/`）里的**所有文件**（含隐藏的 `.nojekyll` 和 `.github/`）上传/推送到仓库根目录，确保 `index.html` 在根。
3. 仓库 **Settings → Pages → Build and deployment**，Source 选择 **GitHub Actions**。
4. 等待 Actions 跑完（通常 1 分钟内），访问 `https://<你的用户名>.github.io/<仓库名>/`。

**已针对子路径部署做好处理：**
- 所有资源用相对路径，`sw.js` 注册用 `new URL('sw.js', document.baseURI)` 适配 `/用户名/仓库名/` 前缀
- `manifest.json` 的 `start_url`/`scope` 为 `./`，安装后从子路径正确启动
- 两个页面（比价 / 记账）都注册了 Service Worker，均可离线

> 若更习惯传统方式：也可在 Pages 的 Source 选 `Deploy from a branch` → `main` / `root`，效果相同，此时可忽略 Actions 工作流。

## 在安卓上运行

### 方式一：本地直接打开（最快）
把整个 `price-compare-app` 文件夹传到安卓手机，用浏览器打开 `index.html` 即可使用（部分浏览器对本地 file 的 Service Worker 有限制，不影响核心功能）。

### 方式二：本地起服务后手机访问（推荐，可安装）
1. 电脑上运行：`python -m http.server 8080`
2. 手机与电脑连同一 WiFi，浏览器访问 `http://<电脑IP>:8080`
3. 浏览器菜单 → **添加到主屏幕**，生成桌面图标，全屏使用、可离线

### 方式三：打包成 APK
如需真正 APK，可用 Capacitor / Bubblewrap 把本目录打包：
```bash
npm i -g @capacitor/cli
npx cap init "喵喵生活" com.example.shengqianmao --web-dir .
npx cap add android
# 用 Android Studio 打开 android/ 目录构建 APK
```
本 App 已按 PWA 规范编写（manifest + service worker），Bubblewrap 也可直接生成 TWA APK。

## 接入真实价格数据

编辑 `js/data.js` 中的 `dataSource.fetchRemote()`，改成请求你的后端接口（返回空数组表示没有线上数据，界面只显示你手动录入的商品）：

```js
async fetchRemote() {
  const res = await fetch('https://your-api.com/prices');
  return await res.json();   // 返回结构见下方；失败时返回 []
}
```

返回结构（每个商品含 `platforms` 报价数组；`qtyInfo` 可选，用于单位价格计算）：

```js
{
  id: 'milk-1', category: 'milk', brand: '爱他美', name: '卓萃 3 段',
  spec: '800g / 罐', emoji: '🥛', accent: '#4a90e2', tags: [],
  updatedAt: 1710000000000,
  qtyInfo: { qty: 2400, unit: '克', label: '每克', per: 800, packs: 3, gift: 0, text: '800克/份 · 3份 · 共2400克' }, // 总数量，用于单位价格对比
  platforms: [
    { key: 'jd', price: 268, promo: '满199减30', stock: true }
    // key 对应 PLATFORMS 中的平台；stock=false 表示无货
    // 到手价由 calc.js 依据 promo 自动算出，比价用到手价
  ]
}
```

电商平台价格通常受反爬与授权限制，实际落地建议使用官方开放平台 API 或合规的数据服务商。加油站油价可接入各地发改委/第三方油价 API。UI 层完全不用改。
